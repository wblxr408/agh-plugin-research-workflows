# 科研工作流 · Research Workflows

核对科研证据、重绘图件、修订答辩稿。

在 AGH 市场安装本包后，从「智能体」打开对应入口，也可在会话输入 `$` 选择 Skill。按提示补充任务材料。

- [主张与证据](skills/workflow-research-evidence/SKILL.md) · `workflow-research-evidence`。提炼科研贡献、核对实验结论和对照依据。
  示例：`$workflow-research-evidence 请核对这项研究的主张、实验条件和证据；我会附上论文段落、结果表或运行记录。`
- [科研图重绘](skills/workflow-figure-redraw/SKILL.md) · `workflow-figure-redraw`。按原始数据与可复核口径重绘已有科研图。
  示例：`$workflow-figure-redraw 请按源数据重绘指定科研图；我会附上原图、数据或生成脚本和目标格式。`
- [科研答辩修订](skills/workflow-defense-revision/SKILL.md) · `workflow-defense-revision`。基于现有答辩稿修订科研叙事和指定页面。
  示例：`$workflow-defense-revision 请基于原稿修订指定答辩页；我会提供原稿、页码、受众和已有证据。`

Skill 和 Bundle 随安装提供。文件、模型与工具沿用当前 AGH 会话配置。
