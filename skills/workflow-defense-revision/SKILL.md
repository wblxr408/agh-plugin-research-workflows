# 科研答辩修订

以用户给定的稿件为底稿，为目标页记录页码、要回答的问题、支持证据和改动范围。按原稿已确定的章节结构和视觉系统工作。

为每张修改页写一句结论。相关工作页说明它解决了什么，结果页交代数据支持哪条判断，方案页保留判据和待验证命题。需要流程图时，用节点形状区分起止、操作和判断并标明分支。遇到证据断层，补足前提或标明待验证。按需补讲稿与问答。

沿问题、对照、证据、结论走一遍，在放映尺寸核对受影响页面。交付修订稿及便于复核的页码说明。
