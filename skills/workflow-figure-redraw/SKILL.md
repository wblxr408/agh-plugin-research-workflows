# 科研图重绘

记录原图的比较对象、方法标签、面板关系和目标尺寸。先判定名称变化是显示别名还是替换数据。回到确认的实验版本、原始结果与生成脚本，明确筛选和聚合口径。

重算会影响读者结论的值，包括样本数、分组统计和配对结果。保留数据到面板的对应关系。在授权范围内更新脚本并按指定格式渲染，在实际尺寸核对可读性、图例、单位、区间和关键值。

交付渲染图、复现入口与必要数据来源。原始数据缺失时说明可核实的范围和所需输入。获准使用示意数据时在图件和说明里标明。
